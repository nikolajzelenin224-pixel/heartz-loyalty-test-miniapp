# Попап «Уведомить» в виджете каталога

Раньше попап отправлял форму в стандартный InSales `/client_account/feedback` только с e-mail - адрес никуда не сохранялся. Теперь он уходит на `https://heartz.immo/ajax/hz-newsletter-subscribe.php` и попадает в Unisender, список 71 «Уведомить о наличии. С сайта.», с метками `site_restock` и `restock_<адрес-товара>` (например `restock_cerebral-shift-thermochrome-t-shirt`), с письмом «подтвердите подписку».

Форма отправляется в iframe внутри попапа: страница не перезагружается, ответ показывается под кнопкой, при успехе поле очищается и попап закрывается через 4 секунды.

## Что поменять в виджете каталога (3 точечные замены, SCSS не трогать)

1. **HTML**: строку `<a class="product-subscription">уведомить</a>` заменить на `1-link.html`.
2. **HTML**: весь блок в самом конце, начиная с `<div class="form-notify-popup">` и до конца, заменить на `2-popup.html`.
3. **JS**: последний блок, начиная с `document.addEventListener("DOMContentLoaded", () => {` и до конца, заменить на `3-popup.js`.

## Как потом уведомлять

В Unisender открыть список 71, отфильтровать контакты по метке `restock_<адрес-товара>` и отправить им письмо о поступлении.
